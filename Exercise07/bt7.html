Câu hỏi thường gặp (FAQ)

+ HTML là gì?
HTML là ngôn ngữ đánh dấu dùng để xây dựng cấu trúc trang Web.
+ CSS dùng để làm gì?
CSS dùng để trang trí, định dạng màu sắc, phông chữ và bố cục cho trang Web.
+ jQuery là gì?
jQuery là thư viện JavaScript giúp viết code thao tác giao diện và bắt sự kiện nhanh, gọn hơn.
+ Responsive Web là gì?
Responsive Web là cách thiết kế giao diện tự thích ứng đẹp mắt trên máy tính, tablet và điện thoại.
